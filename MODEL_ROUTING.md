# Omi v14 — Multi-Model Intelligence

Omi now routes work across three configurable model tiers:
- Luna: routine/high-volume requests.
- Terra: deeper reasoning.
- Astra: hardest end-to-end workflows.
- Explicit `fast`, `deep`, `expert`, and `maximum` modes are supported.
- Automatic escalation uses complexity/tool signals.
- Environment variables can override model IDs.
- `OMI_AI_MODEL` can still force one model globally.

The provider key remains server-side.
