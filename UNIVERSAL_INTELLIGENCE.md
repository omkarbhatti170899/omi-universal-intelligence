# Omi v16 — Universal Intelligence

Omi is now structured as one platform with contextual workspaces:
Personal, Student, Professional, Enterprise, Manager, Developer, Creator and Researcher.

Manager Intelligence is a capability, not the identity of Omi.

The architecture includes:
- universal mode routing
- configurable model routing
- multilingual/localization profile
- accessibility capability flags
- shared memory/research/files/coding/creative/analytics foundations
- verification, audit and human-approval capabilities
