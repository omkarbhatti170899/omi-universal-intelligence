# Omi v17 — Production Hardening

v17 shifts the project from feature expansion to operational readiness.

Added:
- request/error/latency observability
- metrics endpoint
- privacy and retention policy configuration
- production gate validator
- explicit environment configuration
- deterministic production hardening tests

Before public launch, Omi still needs a real deployment, real provider smoke test,
load/security testing, and infrastructure-level monitoring. No claim of live deployment
is made by this package.
